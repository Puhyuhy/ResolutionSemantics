# Historical development note

This file documented an earlier research architecture and no longer describes
the current manuscript. It is retained only so old links remain intelligible;
the detailed earlier text remains available in Git history.

The authoritative paper is now
`paper/latex/paper.tex`, titled **A Finite-Complement Congruence Topology for
Partial Algebras**. Its current scope is summarized in `README.md`.

The `lean/` directory contains supplementary formal developments accumulated
during the project. Some module and theorem names preserve older terminology
for API and provenance reasons; those names should not be read as claims made
by the current paper.
