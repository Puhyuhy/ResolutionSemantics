\title{\textbf{Discrimination by Finite-Complement Completions of Partial Algebras}}
\author{Adrian Puha}
\date{21 August 2026}

\begin{document}
\maketitle

\begin{abstract}
Let $D$ be a partial algebra with carrier $A$, where $A$ may be infinite.  We
consider compatible total completions that contain $A$ pointwise and add only
finitely many new elements.  The main result is a finite-subset discrimination
theorem: for every finite subset of the free compatible completion of $D$,
there is one such finite-complement completion whose canonical homomorphism is
injective on that subset.

For an infinite base this statement is not obtained by the usual
product-of-separators argument, because finite complement over the diagonal
copy of the base is not preserved by binary products.  We therefore give a
direct construction using the finite subterm closure of the elements to be
distinguished.

The same class of completions defines a separated countable uniformity on the
free completion.  For finite bases, its Cauchy completion is proper exactly
when the original algebra is genuinely partial.  For arbitrary bases we give a
simple sufficient condition for properness using a unary context that fixes all
base elements.  All proofs are given in ordinary mathematical form; a separate
machine-checked development is supplementary only.
\end{abstract}
